# Launch checklist

## Content and build

- [ ] Static generator reports 300 guides, 20 model hubs, and 15 topic hubs.
- [ ] Validator reports 344 HTML pages and 343 sitemap URLs.
- [ ] Every guide includes the exact Motorola model context, California sources, and exact-model Parts4Cells category.
- [ ] Desktop and mobile browser review passes on the homepage, guide library, law guide, and representative repair guides.
- [ ] Search, model filters, topic filters, menu, internal links, 404 page, robots.txt, and sitemap.xml work.

## GitHub Pages and domain

- [ ] Public GitHub repository is created with `main` as the default branch.
- [ ] GitHub Pages workflow completes successfully.
- [ ] Custom domain is set to `motorolarepairparts.com`.
- [ ] Only the required apex and `www` DNS records are changed; unrelated DNS and mail records remain intact.
- [ ] HTTPS is enforced after DNS validation.
- [ ] Root, representative guide URLs, `robots.txt`, and `sitemap.xml` are verified over HTTPS.

## Final record

- [ ] Repository URL, deployment run, DNS values, live checks, commit, and build validation output are recorded in `P4C-TASK-030`.
